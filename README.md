# ZombieKiller

## About

A game developed with Unity and C#.

## Genre

Survival / Zombie Shooter

## Features

* Wave-based zombie spawning system
* Survival-focused gameplay
* Player shooting and combat mechanics
* Enemy AI with player tracking behavior
* Currency reward system for defeating zombies
* Weapon upgrade system
* Increasing difficulty through progressive waves
* Health and damage system
* Score and progression mechanics
* Multiple zombie encounters and combat scenarios

## Challenges

One of the main challenges of this project was designing a scalable enemy wave system while keeping the gameplay balanced and engaging.

Additionally, implementing the weapon upgrade system required creating a flexible architecture that allowed player progression through improved damage, fire rate, and combat efficiency without affecting overall game balance.

The enemy AI was designed to continuously track and attack the player, creating constant pressure and encouraging strategic resource management and weapon upgrades.
